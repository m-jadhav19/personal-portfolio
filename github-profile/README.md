# Mandar Jadhav

**Frontend engineer and creative developer in Mumbai.**

I build production interfaces with React, Next.js, Vue, TypeScript, and motion. The work I like best is the kind where craft and shipping sit in the same place: component systems, logistics UIs, WebGL, and interaction that still feels intentional after it hits real data.

Open to interesting frontend work.

## Now

Frontend Engineer at ShipDelight Logistics Technologies, building post-purchase logistics interfaces for merchant and operations workflows. Day to day that means Vue, Nuxt, React, TypeScript, and Tailwind: tables, status flows, and screens that stay fast when the data is real.

Before that I led frontend for IoT dashboards at Futurism Technologies, covering device state, alerts, GraphQL and REST, and Three.js where a spatial view made the telemetry easier to read.
